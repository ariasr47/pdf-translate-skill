Chapter 1 of 4

What B1 is

The library never breaks a line. A translated line has to fit the space the source line used, on one line, or it does not ship.

So a longer translation gets shrunk. Below 0.7 of the source size the build refuses, and that text stays in the source language on a page that is otherwise translated.

The approved fix is to let the text wrap onto a second line, inside a box the author draws, on the same page, with the page count unchanged.

Remember: a translation that will not fit is shrunk, then dropped, and the reader sees the source language.

Remember: nobody kept the failed jobs, so there is nothing to measure a fix against.

What cleared today

Before this: nobody kept the failed jobs, so there is nothing to measure a fix against.

A probe in September found three things that would stop any wrapping work from being trusted. Two of them went away today, as side effects of other merges.

  • The shrink was misreportedMerges printed 2% smaller than the report claimed. Fixed and merged.
  • Repeated labels picked the wrong oneTypography added occurrence IDs. B1 can now address exactly one.
  • The first line movesAll six probe cases shifted the baseline. A drawn box alone does not hold it.

That last one is real work, but it is ordinary work. It is not what has kept B1 parked for two days.

Remember: only baseline anchoring is left in the code; the rest is the evidence problem.

Option A, and the other two

Before this: only baseline anchoring is left in the code; the rest is the evidence problem.

Stop looking backwards for jobs nobody kept. Make the next refusal keep itself.

How should B1 get its evidence?

All three are defensible. Only one produces evidence.

A. Capture hook

  • Evidence arrives without anyone hunting
  • Small, and useful even if B1 never ships
  • The first real case waits for the next refusal

B. Use synthetic

  • Starts now
  • No denominator, so no honest recovery number

C. Stay parked

  • Costs nothing
  • Nothing retains evidence, so the wait does not end

If you do nothing: option C happens by default, and the next refusal is lost like the others.

What a saved bundle would need to contain

The list already exists, written for a human in docs/design/B1-line-wrapping/FAILED-JOB-REQUEST.md. Turning it into a retained artifact is the work.

  • The source PDF and the authored mapping
  • The font files the job used
  • The structured refusal, with the command and library version
  • The affected occurrence's page and position
  • Whether the author permits a box there, and if unknown, say so rather than infer one

Remember: a hook makes evidence arrive on its own; the other two options wait or guess.
