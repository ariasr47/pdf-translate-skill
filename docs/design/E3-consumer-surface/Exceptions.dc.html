C1 · “raising a typed exception on refusal”
What raises, and what is only data
One typed exception exists in the whole package today — strip_text.WidgetTextError. Everything else signals refusal by return code plus a printed line, which a library caller cannot act on.
The line is already drawn, by the product’s own ruling. R5: a verify FAIL is a needs-attention notice and the document is still delivered — only a build refusal withholds it. So the split is not an invention: a refusal that withholds an output raises; an outcome that judges an output returns. Row 32 hit the same distinction from the other side.
Raises — no output exists
PdfTranslateError # base, never raised directly ├── WidgetTextError # exists today ├── MappingError # core unauthored / null target ├── GlyphError # the face cannot draw a char ├── PlacementError # a run cannot be placed at all └── FontError # the subset cannot be built
Each carries the facts as attributes — page, core, char — not only a message, so a service can render the cause without parsing English.
The family is provisional: the audit that enumerates every current refusal path is task 1 of the build, and it decides the final list.
Returns — an output exists and is judged
verdict = run_verify(src, out) verdict.ok # False on a FAIL verdict.gates # one per GATE_NAMES verdict.exit_code # 1, never a raise qa = run_qa(mapping) qa.error_count # data, not an exception seg = extract_segments(…) seg.unextractable_pages # already data today seg.invisible_text_pages # already data today
These already behave correctly and are not touched. extract_segments is the model the rest should follow: it returns its refusal reasons as data and lets main() decide what that means for a console and an exit code.
How the CLI stays byte-identical
def main(argv=None): _console() try: result = retypeset(…) except PdfTranslateError as exc: log.info(exc.console_line) # the exact string printed today return exc.exit_code # the exact code returned today
The exception carries the console line it replaces. That is what keeps the eleven-CLI parity runner green through a change that moves every refusal from a print-and-return into a raise — and it is why the migration can be done one stage at a time, with the runner as the ratchet.
