A library a service can call
Every stage a function taking explicit paths, returning data, raising a typed exception on refusal — no argv, no printing, no sys.exit, no dependence on the working directory. The eleven CLIs stay byte-identical.
What a consumer writes
from pdf_translate import ( strip_text, extract_segments, prepare_font, retypeset, field_fonts, run_verify, run_qa, ) # 1 — strip. Returns what it removed; raises on an unauthored widget map. stripped = strip_text(src, "stripped.pdf", widget_text=wt) # 2 — extract. Returns segments, cores and the warnings it used to print. seg = extract_segments("stripped.pdf", out_dir=work) # … the consumer authors translations.json (references/translations-format.md) … # 3 — fonts, per target language. lang is BCP 47, never a display name. font = prepare_font(face, "ja.ttf", lang="ja") # 4 — retypeset. Progress per page, cancellable between pages, # byte-identical given a fixed timestamp. built = retypeset("stripped.pdf", "segments.json", "translations.json", "out.pdf", timestamp=FIXED, progress=on_page, cancel=stop) # 5 — gates. Already library-shaped since v51. verdict = run_verify(src, "out.pdf", reference_fonts=refs) # 6 — field fonts, for a fillable form. final = field_fonts("out.pdf", "ja.ttf", "final.pdf")
Names are the ones that ship today. Nothing is renamed: pdf_translate already exports a function per stage, and tests/test_import_surface.py pins them. What changes is what they return, what they print, and what they raise.

Both already exist and can be pointed to: references/translations-format.md states the BCP 47 rule with the explicit “not a display name” example, and references/fonts.md names NotoSansJP-VF.ttf and NotoSansSC-VF.ttf and says what the gate does when they are absent.
