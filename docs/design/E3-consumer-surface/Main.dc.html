A library a service can call
Every stage a function taking explicit paths, returning data, raising a typed exception on refusal — no argv, no printing, no sys.exit, no dependence on the working directory. The eleven CLIs stay byte-identical.
What a consumer writes
from pdf_translate import ( run_strip, run_extract, run_prepare_font, run_retypeset, run_field_fonts, run_verify, run_qa, ) # 1 — strip. Returns what it removed; raises on an unauthored widget map. stripped = run_strip(src, "stripped.pdf", widget_text=wt) # 2 — extract. Returns segments, cores and the warnings it used to print. seg = run_extract("stripped.pdf", outdir=work) # … the consumer authors translations.json. "lang" lives in that file and is # a BCP 47 tag — "ja", never "Japanese". references/translations-format.md # 3 — fonts. Takes the face, the mapping it must cover, and the output face. font = run_prepare_font(face, "translations.json", "ja.ttf", reference_fonts=refs) # 4 — retypeset. Progress per unit, cancellable between units. built = run_retypeset("stripped.pdf", "segments.json", "translations.json", "out.pdf", progress=on_page, cancel=stop) # 5 — gates. Already library-shaped since v51. verdict = run_verify(src, "out.pdf", reference_fonts=refs) # 6 — field fonts, for a fillable form. final = run_field_fonts("out.pdf", "ja.ttf", "final.pdf")
Signatures are the shipping ones. The bare names (retypeset, verify, …) keep their exact behaviour — printing, returning an int — because tests/test_import_surface.py pins them and 128 capture blocks call them. The run_* twins are the new, silent surface.

Already satisfied — do not re-derive
The product asked for two specific things in the consumer guide. Both already exist and can be pointed to: references/translations-format.md states the BCP 47 rule with the explicit “not a display name” example, and references/fonts.md names NotoSansJP-VF.ttf and NotoSansSC-VF.ttf and says what the gate does when they are absent.
The bill
