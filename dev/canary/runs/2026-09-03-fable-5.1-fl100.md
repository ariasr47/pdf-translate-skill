Beside the Judicial Council's own FL-100 S, page for page: the same

## What it walked into

1. **Row 27 — the kept title must be tokenized like the run.** The
   original's `/Title` is `FL-100 Petition—Marriage/Domestic Partnership`
   and the notice quotes it verbatim. The scan's run is `Petition Marriage
   Domestic Partnership`: `FL` is under the four-letter floor and `100` is
   not a word, so the run's key never equals the title's key and row 20's
   keep does not fire. The author guessed and allowlisted both spellings.
2. **Row 28 — `right` shrinks before it anchors.** A right-anchored label
   is scaled to the room right of the *original* origin before being
   placed on the right edge, so `SUCURSAL:`, `CIUDAD Y C.P.:` and
   `Pág. N de 3` had to fit the old width when the room to their left was
   free.
3. **Row 29 — an override-covered core still needs a plain value.** The
   coverage check runs before overrides and the placement gate wants
   every non-null target verbatim, so a core fully replaced by override
   parts must also carry a plain translation that is never drawn.
4. **Row 24, again** (ligatures): it strips GSUB from its subsets
   (`strip_liga.py`), the third model to work around it.
5. **P7, again** (the notice): `post.py`, a fifth script.
6. **Friction, not rowed:** `pipeline.py init` cannot re-strip with
   `--widget-text` without re-extracting, so it called `strip_text.py`
   directly; a core shared between roles (`Petitioner` as a header and as
   six checkbox labels) has one translation and one alignment, so the
   bare labels went into `skip` and each `Demandante` became an override
   part on its neighbour.

## Judgment calls it made and disclosed

- Ten pushbuttons had lost their scripts with the XFA layer: Print / Save
  / Clear re-captioned and re-wired to the viewer's standard actions on
  the same widgets; the five link-style buttons (dead links) hidden — the
  fields still exist, so parity holds — and their words placed in the
  Spanish sentences as plain text, no longer blue, no longer clickable.
  Structure first, and said.
- 28 mixed-style lines placed as overrides with per-part x from font
  metrics; 8 merges; 9 `right`, 8 `center`; `run.sh` rebuilds the whole
  file in about two seconds.
