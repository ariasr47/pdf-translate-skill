Where the time actually goes

Scripts on a 4-page form finish in seconds. The half hour is you writing the mapping and looking at pictures. After the first extract, do not re-run strip / extract / font unless the source PDF or the character set changed.

  1. Edit translations.json
  2. pipeline.py rebuild (retypeset + verify)
  3. pipeline.py render (PNGs at ~110 dpi)
  4. Look. Fix. Loop. Budget 2–3 visual passes. The first build is never right.

FieldsSame names and types as the original.
FillA typed value and a checkbox survive save/reopen.
InkPage still has roughly the same dark pixels. Catches invisible glyphs.
LeakA leftover English sentence fails. One proper noun does not.
ScanPicture of a page with no text layer → halt, name OCR.
Placement--translations: every authored line must appear in the output text. Missing lines are listed. Omit the flag: this gate does not run.
