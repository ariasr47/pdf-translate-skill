# Decisions — pdf-translate

Append-only. One entry per durable decision: what was decided, why, where
it was first written down, and its status. **Status is `active` or
`superseded by D-NN`, and nothing else in an entry is ever edited.** A
decision that replaces an older one gets a new entry at the end and the
old entry's status changes. IDs are never reused. Dates are when the
decision was first recorded; decisions older than the repository's first
commit (31 August 2026) carry that date.

The one-line rules in `AGENTS.md` point here. `dev/STATUS.md` says what
is open; `dev/goals/PROGRAM.md` holds the bars; this file holds the why.

## 2. Locked behaviours

the record that locked it. Every line has a test in `pdf-translate/tests/`
or a verdict in `pdf-translate/corpus/verdicts.json`, and the brief's
closing note names it. A sitting that changes one of these changes the
test that locks it and says so here by **appending** a row, never by
editing one. Rows 01–31 and the lane B rows are briefs under `dev/goals/`;
the audit rows are `docs/RESEARCH-AND-FINDINGS.md` §4 and §10 and the
audit-roadmap table in `PROGRAM.md`.
